# 访问统计数据地球重设计

## 已确认的设计

用户选择精致数据地球、地球所在展示区域一起调整、增强交互，并跟随网站明暗主题。

最新确认：移除中国省份显示及中国/世界区域切换，只保留世界视图和国家级统计。删除本组件的省份地图请求、渲染及聚合；中国作为国家继续显示。不调整采集、请求头或后端。

- 浅色：浅灰展示区、具有光照明暗的蓝灰实体球面、细密大陆点阵与青绿色访问区域。
- 深色：深蓝灰球面、克制的大气边缘光与青绿热点。
- 使用现有地理数据与真实访问量。球体遮挡背面国界；热点只表示统计期内的访问量，不表示实时在线位置或访客之间的连线。
- 世界地图默认朝向亚洲并缓慢自转，颜色按国家级浏览量归一化。
- 支持拖拽、悬停/触摸查看、暂停/继续、自转复位。键盘方向键旋转，Home 复位。手机保留纵向滚动。
- 浅色/深色实时切换，减少动态效果偏好下默认静止；不可见时停止绘制。窄屏球体完整呈现，榜单下移。

## 范围和技术

修改 `astro/src/lib/globe-3d.ts`、`astro/src/components/stats/Globe3D.tsx`、`DualModeGeoMap.tsx`、`StatsDashboard.tsx`，增加地理采样辅助模块和局部 CSS。继续使用现有 Three.js，不新增依赖。统计 API 与数据口径不变。公开和后台共用的统计组件同步更新。

稳定采样替代随机稀疏散点，独立实体球面负责深度遮挡，细线和圆形粒子负责地理表达。GeoJSON 单次加载并支持取消；数据/主题更新不再重复请求地图。异常提供 2D 回退，销毁清理异步请求、监听器和 GPU 资源。

## 验收

`npm run build` 与 `npx vitest run` 为硬门禁。浏览器验证实际球面遮挡、世界视图及 2D/3D 切换、数据提示、旋转控制、主题切换、2D 回退、快速卸载、减少动态效果及 1440/390/320px 布局；保存截图。仅完成本地修改和验证，发布另按实际部署要求处理。

本次不改变后端或数据库；可独立还原所列组件、渲染模块和样式。保持工作区已有的 Caddy 和认证相关修改。
