# 全站科幻简约改造设计

## 目标

将已确认的科幻简约视觉从独立 Demo 推广到正式站点：首页、内容页、关于、标签、归档、友链、留言、画廊、登录、管理后台与共享布局。

## 设计令牌

- 画布：浅色 `#f1f3f5`；暗色 `#0e1114`。
- 文字：石墨 `#16191d`；暗色 `#e8ecf0`。
- 唯一强调色：低饱和青 `#0b6d76`；暗色 `#3fa8b2`。
- 结构线：冷灰细线；无紫色、无霓虹光晕、无大面积渐变。
- 字体：Geist Sans / Geist Mono / Noto Sans SC。
- 科幻元素：细网格、坐标、序号、等宽短标签、克制动效；不堆 HUD。

## 页面结构

### 首页
- 不对称 Hero：左品牌文案 + CTA，右 CSS 轨道仪表。
- 最新文章保留真实数据，编号索引替代三列卡片。
- 侧栏信息合并为简洁区块；删除重复轮播/装饰。
- 保留文章/标签统计与登录入口。

### 内容页
- 文章卡片改为编号行/细线分隔；保留封面缩略。
- 标签、归档、友链、留言、画廊、关于统一细线与网格语言。

### 后台
- AdminSidebar 与 StatsCard 统一令牌；减少阴影与玻璃拟态。

### 共享
- Header/Footer 使用同一令牌与细线；移动菜单保留键盘可达。

## 约束

- 不改业务逻辑、接口、鉴权、数据流。
- 不新增依赖。
- React 组件必须 `export default`。
- 保留现有未提交工作（已提交）。
- 深浅主题均需可读。

## 验收

- `npx vitest run` 通过。
- `npm run build` 通过。
- 关键路由浏览器截图与横向溢出检查。
- 移动菜单、登录入口、后台导航可用。
