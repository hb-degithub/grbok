# 科幻简约首页 Demo 设计

## 目标与边界

为胡巴的博客制作一个可独立访问的首页视觉 Demo，验证科幻简约方向。Demo 使用 `/sci-fi-demo` 路由，不替换首页、不修改现有布局或业务功能、不引入新依赖。现有未提交修改全部保留。

## 视觉语言

- 设计定位：可阅读的个人技术实验室，而非游戏控制台。
- 参数：`DESIGN_VARIANCE: 7`、`MOTION_INTENSITY: 4`、`VISUAL_DENSITY: 4`。
- 色彩：冷白与银灰画布、石墨文字、单一低饱和青色点缀。禁止紫色、霓虹光晕和大面积渐变。
- 字体：沿用本地 Geist Sans、Geist Mono、Noto Sans SC。等宽字体只用于序号、坐标和短标签。
- 纹理：低对比度坐标网格、细刻度和结构线；不以大量 HUD 或透明卡片堆叠科幻感。

## 页面结构

1. 独立导航：博客标识、少量真实站内入口、移动端可展开菜单。
2. 不对称 Hero：左侧为品牌、明确的中文写作定位与文章 CTA；右侧为 CSS 几何轨道和坐标标记。无虚构统计。
3. 内容区：少量精选阅读或主题导航，使用真实的 `/posts`、`/tags`、`/about` 链接。
4. 页脚：沿用 `SITE_CONFIG` 中的品牌与备案链接。

## 交互与可访问性

- 语义 HTML、跳至内容链接、页面描述、可见键盘焦点。
- 移动菜单可展开、关闭并按 Escape 退出，不依赖仅悬停可见的信息。
- 390px 与 1440px 均无横向溢出，交互目标至少 44px。
- 动画仅使用 `transform` 和 `opacity`，遵循 `prefers-reduced-motion`；无 JavaScript 时主体内容仍可读。

## 验收

- 新文件限定为 Demo 路由、必要的 Demo 组件、Demo 局部样式和对应测试。
- Playwright 验证品牌、CTA、真实导航、移动菜单、Escape 和移动端溢出。
- `npx vitest run` 与 `npm run build` 成功。
- 通过浏览器截图检查桌面与移动端层级、间距、换行及视觉一致性。

## 后续

本 Demo 只用于确认设计方向。用户认可后，再评估将设计令牌与组件迁移至真实首页及其他页面；不在本阶段扩大范围。
