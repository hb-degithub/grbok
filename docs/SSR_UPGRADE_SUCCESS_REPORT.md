## 四、架构变更

### 之前（SSG模式）

```
用户请求 → ESA缓存 → Caddy → 静态HTML文件
```

**问题**: 新发布的内容需要重新构建 + 刷新ESA缓存

### 现在（SSR模式）

```
用户请求 → ESA缓存（静态资源）→ Caddy → Node.js SSR服务器 → 动态生成HTML
```

**优势**: 新发布的内容立即可访问，无需构建和刷新缓存
